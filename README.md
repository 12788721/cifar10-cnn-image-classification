# CIFAR-10 Image Classification using CNN

## Project Overview

This project implements a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset into 10 categories.

## Dataset

The CIFAR-10 dataset contains:

* 60,000 color images
* 10 classes
* 50,000 training images
* 10,000 testing images

Classes:

* Airplane
* Automobile
* Bird
* Cat
* Deer
* Dog
* Frog
* Horse
* Ship
* Truck

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Scikit-learn

## Model Architecture

* Conv2D
* MaxPooling2D
* BatchNormalization
* Dropout
* Dense Layers
* Softmax Output

## Results

Test Accuracy: 0.824
Test Loss: 0.58
